# Chaqui · página de prueba

Página pública con el widget del asistente de IA de Ahumadores Chaquiro, para que otras personas prueben el agente.
No contiene claves ni datos internos. El backend vive aparte (AWS Lambda) y solo acepta llamadas desde orígenes autorizados.

Publicada con GitHub Pages: https://lucasrpor1990.github.io/chaquiro-agente-demo/
